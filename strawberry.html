📱 この修正版なら、 スマホ/タブレット → 画面下の◀▶で操作可能 PC → キーボードの左右キーで操作可能 に両対応になっています。 👉 ボタンのデザインをもっと「イチゴ風」にしたい？それともこのシンプル版でいい？ あなた: 画面を大きくしたい ChatGPT: 了解しました！ 画面を大きくして、キャラクターや果物の見た目をそのままアスペクト比を保って描画する形に調整できます 👍 例えば、画面サイズを 横800 × 縦1000 に広げるようにすると迫力が出ます。 修正版の例を置きます👇 python コピーする 編集する import pygame import random import sys pygame.init() # === 画面サイズを大きくする === WIDTH = 800 HEIGHT = 1000 screen = pygame.display.set_mode((WIDTH, HEIGHT)) pygame.display.set_caption("ロフィアくんキャッチゲーム") clock = pygame.time.Clock() # === 画像読み込み（アスペクト比を維持してスケーリング） === def load_image(path, scale_width=None, scale_height=None): img = pygame.image.load(path).convert_alpha() if scale_width and scale_height: img = pygame.transform.smoothscale(img, (scale_width, scale_height)) return img basket_img = load_image("basket.png", 150, 100) rofiakun_img = load_image("rofiakun (1).png") # 元のアスペクト比を維持 fruit_img = load_image("strawberry.png", 60, 60) # キャラをアスペクト比維持で拡縮 rofiakun_width = 200 rofiakun_height = int(rofiakun_width * 0.517) # ユーザー指定の比率で計算 rofiakun_img = pygame.transform.smoothscale(rofiakun_img, (rofiakun_width, rofiakun_height)) # === ゲームオブジェクト === class Basket: def __init__(self): self.image = basket_img self.rect = self.image.get_rect(center=(WIDTH//2, HEIGHT-80)) def draw(self): screen.blit(self.image, self.rect) class RofiaKun: def __init__(self): self.image = rofiakun_img self.rect = self.image.get_rect(center=(WIDTH//2, HEIGHT-150)) def draw(self): screen.blit(self.image, self.rect) class Fruit: def __init__(self): self.image = fruit_img self.rect = self.image.get_rect(center=(random.randint(50, WIDTH-50), -30)) self.speed = 5 def update(self): self.rect.y += self.speed def draw(self): screen.blit(self.image, self.rect) # === ゲーム開始 === basket = Basket() rofiakun = RofiaKun() fruits = [] score = 0 font = pygame.font.SysFont(None, 50) def draw_text(text, x, y): img = font.render(text, True, (255,255,255)) screen.blit(img, (x, y)) while True: for event in pygame.event.get(): if event.type == pygame.QUIT: pygame.quit() sys.exit() keys = pygame.key.get_pressed() if keys[pygame.K_LEFT] and basket.rect.left > 0: basket.rect.x -= 8 if keys[pygame.K_RIGHT] and basket.rect.right < WIDTH: basket.rect.x += 8 if random.randint(1, 25) == 1: fruits.append(Fruit()) # === 更新 === for fruit in fruits[:]: fruit.update() if fruit.rect.colliderect(basket.rect): fruits.remove(fruit) score += 1 elif fruit.rect.top > HEIGHT: fruits.remove(fruit) # === 描画 === screen.fill((50, 150, 200)) basket.draw() rofiakun.draw() for fruit in fruits: fruit.draw() draw_text(f"Score: {score}", 10, 10) pygame.display.flip() clock.tick(60) 💡 この変更で 画面が 800×1000 に広がる ロフィアくんのアスペクト比が 0.517:1 固定 果物やバスケットもつぶれない ようになります！ 👉 次に「操作用のボタンを画面下につける（タッチ操作対応）」に進めましょうか？ あなた: html にして ChatGPT: なるほど！では、先ほどの「落ち物キャッチゲーム」を HTML + JavaScript + Canvas で動くように書き直しますね。 キャラクターのアスペクト比を保ったまま描画し、操作用のボタン（スマホ操作向け）もつけて、画面も大きめにします。 以下が完成版のサンプルHTMLコードです👇 html コピーする 編集する ロフィアくんキャッチゲーム
